## 解釈上の注意

- 白色・有色ノイズは、各静止区間から一次ドリフトを除いた後に分離した。
- 量子化幅はMT6701の14 bit出力から `360 / 2^14` degとした。

- 機構の微小振動や固定治具の動きもセンサーノイズに含まれるため、装置を剛に固定する。
