# オブザーバーとモデル風シミュレーションの後続計画

HBKの係数同定後に行うオブザーバー評価を、基準性能、係数ずれへの感度、センサーの非理想性、実測風との照合に分けて進める。モデルを段階的に複雑にし、どの要因で誤差が増えるかを切り分ける。

| ID | タスク | 主な確認内容 | 状況 |
|---|---|---|---|
| OW-01 | 採用係数の登録 | 軸・構成ごとの `I`、`K`、`c`、`tau` を記録し、`b=0`として選択可能にする。`c_ball`はIN・OUT軸で共通値とする。 | 完了 |
| OW-02 | 新モデルで従来比較を再実施 | 採用モデルをプラントと対応する推定式に適用し、過去に比較したESO、RTS、静的換算、LPFを標準入力で再計算する。広範な風条件評価はOW-03で行う。RTSは将来の計測値を使うオフライン方式として扱う。 | 完了 |
| OW-03 | 係数一致・理想センサーで基準評価 | プラントと推定モデルに同じ係数を使い、係数のモデル誤差がない条件で、平均風・乱流・ガストを評価する。調整用と評価用の風入力を分ける。 | 未着手 |
| OW-04 | 係数ずれに対する感度評価 | プラント係数と推定モデル係数の `I`、`K`、`tau`、`c` をずらし、推定性能への影響を評価する。個別ずれと組み合わせずれを調べる。 | 未着手 |
| OW-05 | センサー非理想性と最終オブザーバー選定 | 計測角へのノイズ、量子化、遅延などを加えて再評価し、実装可能性も考慮してオブザーバーを選ぶ。 | 未着手 |
| OW-06 | 実風データとの妥当性確認 | 校正済み風速計との実測比較を行う。計測位置とサンプリング周期の違いを考慮し、モデル風シミュレーションだけで確認できる範囲も記録する。 | 未着手・比較に使う実測データと条件を確認 |

## 評価段階の定義

### OW-02：新しい運動モデルで比較をやり直す

過去のオブザーバー比較は参考になるが、そのまま新しい係数同定結果に対する評価とはみなさない。過去の解析から採用係数とモデル式が変わっているため、新しい非線形プラントを使って再計算する。

プラント側では、採用した `I`、`K`、`c`、`tau` と `b=0`を使う。推定側でも既知として扱うモデル項を一致させる。速度依存損失を直接使わない静的換算やLPFは、動特性を利用しない比較基準として残す。ESOとRTSは、採用損失項をモデルに含める方法を定めたうえで比較する。RTSの結果はオンライン実装可能な方式と混同しない。

### OW-02の結果

新しいBALL係数をプラントと非線形推定器に反映し、IN・OUT軸を同一のKaimal風入力で別々に再計算した。旧モデルで選んだESO、RTS、LPFの設定は固定し、角度センサーは理想値とした。標準入力は平均風速2.0 m/s、最大3.5 m/s、目標乱流強度20%、100 Hz、評価時間30〜150 sである。評価中の最大絶対角度はIN 18.94°、OUT 18.16°で、±45°以内に収まった。

オンライン候補では3状態ESOの風速RMSEがIN 0.1030 m/s、OUT 0.1283 m/sで、各軸の今回の設定で最小だった。RTS 3状態はIN 0.0057 m/s、OUT 0.0080 m/sと最小だが、将来の角度データを使うオフライン方式である。OUTの4状態ESOは旧設定を新係数に適用すると発散し、RMSEは49.55 m/sとなった。設定を新モデル向けに再調整していないため、この結果は最終的な方式選定ではなく、OW-03以降での再調整が必要であることを示す。

以前の平均3.75 m/s・最大6 m/s条件も安全確認として計算したところ、最大絶対角度はIN 59.43°、OUT 54.63°となり、±45°を超えた。したがって、その風条件の評価には可動限界の扱いが必要である。

再現スクリプトは `src/run_ow02_hbk_observer_rerun.py`、設定は `config/ow02_hbk_observer_rerun.json`。数値表、グラフ、詳細な条件と考察は `results/observer_wind/ow02_baseline/OW-02_REPORT.md` を参照。

### OW-03：係数一致条件での基準性能

この段階では、プラントと推定モデルに同じ機械係数を与える。したがって係数ずれによるモデル誤差はない。ただし、風入力の違い、センサー誤差、推定方式の近似による誤差は別であり、ここではセンサー誤差をまだ加えず、方式ごとの基本性能を評価する。

同じ風の時系列を各方式に与える。風入力は調整用と評価用に分離し、平均風、乱流、ガストを含める。風速上限は6 m/s、乱流ケースの目標乱流強度は20%とし、生成後の実際の乱流強度とスペクトルを併記する。

### OW-04：係数ずれへの感度

プラントには採用係数を使い、推定モデルの係数だけをずらす。対象は `I`、`K`、軸別 `tau`、軸共通 `c_ball` とする。係数ずれの幅は、同定のばらつきと質量・取付位置などの計測誤差から設定根拠を示す。最初に一つずつ変え、その後、現実的な組み合わせを調べる。性能を最大化するための反復最適化は行わない。

### 共通の評価指標（OW-03・OW-04・OW-05）

RMSEは、評価区間における推定値と既知の真値との差を二乗平均平方根で表す。オブザーバーの評価では、まず推定風速と入力した真の風速のRMSEを示し、必要に応じて力・トルクのRMSEも別に示す。OW-03では係数一致条件の基本性能、OW-04では係数ずれによる性能変化、OW-05ではセンサー非理想性を加えた性能変化を評価する。RMSEだけでなく、偏り、絶対誤差の95パーセンタイルと最大値、位相・遅れ、ガストピークの追従、無風時の誤推定も共通して確認する。

### OW-05：センサーモデルと選定

まず理想センサーで機械モデルと係数ずれの影響を切り分け、その後に計測角へセンサーノイズ、量子化、遅延などを加える。パラメーターは過去のセンサー解析結果または実測したセンサー特性から設定する。モデル誤差とセンサー誤差の両方を含む条件で候補方式を比較し、オンライン処理の可否、誤差、遅れを踏まえて最終オブザーバーを選ぶ。OW-03・OW-04で得る選定は暫定とし、OW-05の結果を含めて確定する。

### OW-06：実測風との照合

モデル風シミュレーションは、設定した数値モデルの範囲内での評価であり、実風に対する妥当性を単独では証明しない。利用可能な校正済み風速計と装置の実測ログを確認し、比較条件が適切なら照合を実施する。風速計と装置の距離・高さ・向き、およびサンプリング周期の差を記録する。既存ログで必要条件を満たせない場合は、追加計測の条件と比較手順をまとめ、妥当性の結論は保留する。

## OW-01の結果と使い方

採用係数は `config/hbk_model_coefficients.json` に保存した。軸と構成を明示して選択する。たとえば、IN軸で球を取り付けた構成は次のように指定する。

```bash
python 06_Analysis/simulation/src/hbk_model_coefficients.py --axis IN --configuration BALL
```

選択結果には、慣性モーメント、復元係数、ロッドと球の二乗抗力係数、粘性減衰係数、および一回積分法で求めたクーロン摩擦係数が含まれる。存在しないケースや、`b`がゼロでない係数はエラーとして扱う。同じモジュールの `simulate_hbk_plant()` は、風による力を入力として、二乗抗力と滑らかに近似したクーロン摩擦を含む非線形プラントをRK4で数値積分する。力の作用腕は機械係数の台帳から推定せず、呼び出し時に明示する。係数台帳には、IN・OUT両軸のスペーサー5構成（`SP00`から`SP04`）と球あり構成（`BALL`）を登録した。

球あり構成の `I` と `K` には、有効な球重心腕長180.61 mmと質量3.9 gを用いた。180.61 mmは自由振動の周期フィットで選んだ有効値であり、実機の寸法を独立に再計測して確定した値ではない。球の抗力係数 `c_ball` は方式Aで同定し、IN・OUT軸に共通の値1.3775×10⁻⁵ N·m·s²/rad²を使う。ロッド抗力 `c_rod` は理論値を使い、球あり構成では球に覆われていないロッド長に応じて補正する。この幾何補正により、球あり・球なしで合計抗力係数 `c` は異なるが、`c_ball` 自体は軸共通である。`tau`は軸別の値を使い、すべての係数で`b=0`とした。

旧 `config/real_wind_doe.json` とその結果は、以前の単一構成モデルを使ったステージ2の記録として保持する。採用済みHBK係数で計算した結果として扱い直すことはしない。新しい係数台帳、選択関数、プラント積分関数をOW-02以降で使用する。

## 係数の出典

| 係数 | 出典と扱い |
|---|---|
| `I`、`K`（SP00〜SP04） | IHB-02の自由振動周波数同定。軸と構成ごとの値を使用。 |
| `I`、`K`（BALL） | IHB-05で位置補正した値。有効腕長180.61 mm、球質量3.9 g。 |
| `c_rod` | IHB-04の円柱抗力理論値。軸共通とし、球あり構成では露出ロッド長で補正。 |
| `c_ball` | IHB-05方式Aの単調振幅フィットで同定したIN・OUT軸共通の値。 |
| `tau` | IHB-03の単調平滑振幅を用いた一回積分法で同定した軸別の値。IHB-05でもこの値を固定して使用。 |
| `b` | 採用した同定条件に従ってゼロに固定。 |

## OW-01の確認内容

係数台帳には重複のない12ケースが登録されている。全ケースで選択処理を確認し、BALLでは位置補正後の慣性モーメントと復元係数が返り、スペーサー構成ではIHB-02の値が保持されることを確認した。プラント積分関数には、力をゼロ、初期角をゼロ以外とした自由応答を入力し、有限値の軌跡が得られることを確認した。旧ステージ2の実風DOEは再実行していない。オブザーバーの比較と選定はOW-02からOW-05の各段階で行う。
