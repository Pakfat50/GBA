# WBS2.4 — 10 Hz応答に向けた球・ロッド・錘の小型化探索

## 結論

現在のグリス、ダンパー寸法、軸別`τ`を固定した条件では、**機械系の線形化ゲインだけを満たす候補はありますが、10 Hzの風速波形をRTSで安定して復元できる実用解は見つかりませんでした**。小型化と減衰を両立する候補は錘が約5.8〜8.9 kgとなり、10 Hzの角度信号はセンサー雑音より小さい値です。RTSの`Q`を上げると推定ゲインは0.5を超える場合がありますが、位相と風速RMSEが悪化し、入力した±0.5 m/sの正弦波形は再現できません。

2,000,000点のランダム探索で、両軸の静的角度・`ζ≥0.70`・10 Hz機械ゲイン`≥0.5`を同時に満たしたのは16点でした。厳密な過減衰（`ζ≥1`）を両軸で満たす点は0点です。`ζ=0.70`は線形2次系なら約4.6%のステップオーバーシュートに相当しますが、固定クーロン摩擦を含む実際の系に対するオーバーシュート保証ではありません。

## 条件と固定値

| 項目 | 探索・検証条件 |
|---|---|
| 球径 | 30〜100 mm。30 mmを下限とする |
| 発泡球密度 | 発泡率60倍を固体PS密度1,050 kg/m³の1/60とし、17.5 kg/m³を使用。球質量は球形として算出 |
| 球中心腕長 | 球半径+5 mm以上、最大500 mm |
| ロッド | CFRP相当密度1,600 kg/m³、外径2〜8 mm、肉厚0.5 mm（暫定） |
| 錘 | 腕長2〜70 mm、探索計算上の質量範囲0.05〜1,000 kg。1,000 kgはユーザー指定の上限ではなく数値探索範囲 |
| ダンパー | WBS2.3と同じ軸径8 mm、接触長30 mm、半径すきま1 mm、同じグリスのまま固定 |
| 粘性係数`b` | Couette近似値`4.613407×10⁻³ N·m·s/rad`に固定 |
| 摩擦トルク`τ` | IN `7.945731×10⁻⁵ N·m`、OUT `1.769497×10⁻⁴ N·m`に固定 |
| 判定 | 8 m/sで両軸60°以内、線形化減衰比`ζ≥0.70`、10 Hzの機械ゲイン`≥0.5`（DC比で−6 dB以内） |
| 10 Hz入力 | 平均2 m/s、振幅0.5 m/sの正弦波。WBS2.3と同じ100 Hzサンプリング、実センサーモデル、3ノイズseedを使用 |

球中心腕長をロッド長の代表値として扱い、ロッド全長を「支点から球中心まで+球半径+5 mm」と仮定しました。既存係数から基準球・錘・アルミ管の寄与を差し引き、残りを固定構造の寄与として扱っています。この固定残差とCFRP管近似は、CADや実測質量分布がない状態での暫定モデルです。

## 候補比較

次の3案は同じ2,000,000点探索から選びました。いずれも線形化した機械条件は通りますが、非線形プラントの実応答では摩擦の影響で角度振幅がさらに小さくなりました。

| 候補 | 球径 / 球質量 | 球中心腕長 / ロッド長 | 錘質量 / 錘腕長 | `ζ` IN / OUT | 機械ゲイン IN / OUT | 8 m/s静的角度 IN / OUT | 非線形角度振幅 IN / OUT |
|---|---:|---:|---:|---:|---:|---:|---:|
| 最小球径 | 30.03 mm / 0.248 g | 29.97 / 49.98 mm | 8.894 kg / 2.09 mm | 0.727 / 0.712 | 0.619 / 0.613 | 0.14° / 0.14° | 0.00091° / 0.00050° |
| 最小錘質量 | 44.86 mm / 0.827 g | 43.45 / 70.88 mm | **5.836 kg** / 2.75 mm | 0.737 / 0.723 | 0.513 / 0.504 | 0.54° / 0.54° | 0.00299° / 0.00163° |
| 最大線形信号 | 67.18 mm / 2.778 g | 42.54 / 81.13 mm | 6.962 kg / 2.37 mm | 0.716 / 0.703 | 0.522 / 0.513 | 1.15° / 1.16° | **0.00719° / 0.00371°** |

「最小球径」は球を下限まで縮められますが、錘が重く、信号が最小です。「最小錘質量」は今回通過した集合内で錘を最軽量にした候補です。いずれも8 m/s時の静的角度は60°制約を大きく下回り、測定角度の利用範囲をほとんど使いません。「最大線形信号」でも、非線形モデルの10 Hz角度は仮定ノイズ標準偏差0.02°のIN約36%、OUT約19%です。実センサーモデルの白色・有色ノイズ合成RMSは約0.018°です。

## 固定`τ`が効く大きさ

ベスト信号候補でも、2 m/sを中心とする±0.5 m/s風速正弦波が作る線形化トルク振幅は約`1.00×10⁻⁴ N·m`です。固定摩擦トルクとの比はINで約0.79、OUTで約1.76です。最小球径候補ではトルク振幅が約`1.41×10⁻⁵ N·m`に下がり、`τ`はINで約5.6倍、OUTで約12.5倍になります。このため、線形粘性ゲインの条件を満たしても、微小な10 Hz運動が`τ`に埋もれます。

## RTSの雑音込み検証

3案について`Q=0.003, 0.01, 0.03 N/sample`を比較しました。各設定は3 seedで実行しています。たとえば最小錘質量候補では、`Q=0.003`でINの平均ゲインは0.515ですがOUTは0.299、平均RMSEはそれぞれ0.907、1.108 m/sでした。`Q=0.01`では両軸の平均ゲインが0.5を超えますが、RMSEはIN 1.604、OUT 1.856 m/sとなり、入力の振幅0.5 m/sより大きくなります。seed間の位相差も大きく、安定した波形再現とは判定できません。

ベスト信号候補でも、`Q=0.01`時の平均ゲインはIN 0.801、OUT 0.635ですが、RMSEは0.666、0.843 m/s、seedごとの位相はIN −16〜−33°、OUT −17〜−41°でした。ゲインだけを見れば目標を越える設定がありますが、実際の風速波形を回収したとは言えません。

## 判定と次の設計判断

- 球径を30 mmにしても、固定`τ`下の10 Hz信号は改善しません。小球化を優先した設計は、球と錘のどちらを選んでもRTS再現性を満たしません。
- 錘最軽量候補でも約5.84 kgです。支点から約2.75 mmに錘重心を置く数学上の配置であり、実装可能性・軸荷重・保持構造を評価していません。
- 線形化減衰比が0.70台の候補は許容オーバーシュートを想定した一次候補に留まります。厳密な過減衰案は今回のランダム探索では得られていません。
- よって、現在のグリス幾何と`τ`を保持したまま、球・ロッド・錘だけで10 Hz風速波形を復元する設計解は確認できませんでした。これは記載した寸法・材料モデルと探索範囲内の結論です。
- 10 Hz復元を必須とするなら、後続検討では機械寸法だけでなく、軸`τ`の低減、センサー雑音の低減、または観測器・計測原理の見直しが必要です。これらは今回固定条件の外なので、ここでは候補寸法へ反映していません。
