# OW-07 球・錘の質量配置による摩擦相対効果の評価案

## 状態と目的

- 状態: WBS 0.1〜0.3完了、WBS 1.1完了。新たな実測は行わず、既存データ・部品情報・公開資料を使う。次にWBS 1.2で、最小限の球・錘変更候補について風速範囲と不感帯を見積もる。難しい場合に限り、ダンパー追加案を評価する。
- ブランチ: `ow07-hardware-bandwidth-design`
- 目的: オブザーバー変更だけでは広い条件に使える改善を確認できなかったため、球・錘の寸法、質量、位置を変え、慣性モーメント`I`と復元係数`K`を下げる。その際、ほぼ一定とみなせる軸のクーロン摩擦`τ`を相対的に効かせ、共振応答を抑えられるかを調べる。最大約8 m/sの風速範囲を角度リミット内で保つ球サイズも同時に検討する。

まず球・錘の小さな変更で成立する範囲を調べる。質量配置だけでは目標を満たせないと判断した場合は、同じ評価軸でダンパー追加案を比較する。センサー、推定器、無線方式は今回の設計変数にしない。

## 問題の物理的な見立てと今回の仮説

今回の主問題は、現行の固有振動数付近で角度応答と係数誤差感度が大きくなることにある。小振幅の粘性減衰モデルでは、風トルクから角度までの伝達は概ね

```text
H(ω) = Θ/M_w = 1 / (K - Iω² + j b_eff ω)
```

となる。共振付近では分母が小さくなるため、同じ風トルクでも角度応答が大きくなり、`I`や`K`のずれも角度・逆推定風へ強く表れやすい。

今回の質量配置変更の仮説は、**`I`と`K`を下げ、ほぼ変わらない軸クーロン摩擦`τ`の相対的な影響を大きくすることで、振動の成長・持続と共振付近の感度を抑えること**である。これは乾性摩擦が支配的な応答を作る案で、粘性減衰係数`b`による古典的な臨界減衰・過減衰（減衰比`ζ≥1`）とは異なる。`τ`だけから粘性減衰比や臨界減衰比を定義することはできない。WBSでは、まず最小変更の乾性摩擦支配案を評価し、それで目標未達の場合に粘性ダンパーを加えた`ζ`掃引へ進む。

クーロン摩擦が1周期で失うエネルギーは、振幅`θ_A`の小振幅近似で約`4τθ_A`、ばねに蓄えられる最大エネルギーは約`Kθ_A²/2`である。したがって比`8τ/(Kθ_A)`が大きいほど摩擦損失の相対寄与が大きい。`K`を下げるとこの比は上がるが、同時に静止摩擦による角度の停滞・ヒステリシスも相対的に大きくなり、低風速の不感帯や再現性悪化を招く可能性がある。設計案は振幅減衰だけでなく、微風応答と静止時の角度ばらつきも評価する。

`K`を下げると同じ風速で角度が増えるため、約8 m/sで角度リミット内に収めるよう球径・球位置を調整する。静的釣合いの一次近似は`M_w ≈ K sinθ`、`M_w ≈ 0.5ρCd Aℓ_w U²`なので、同じ腕長・目標角・最大風速を保つなら必要な受風面積`A`は概ね`K`に比例し、球径`D`は概ね`√K`に比例する。ただし球の質量・重力モーメントが`I`,`K`にも戻り込むため、実際は全体を反復計算する。また起動時には風トルクが軸摩擦を上回る必要があるため、`τ`による不感帯も含めて判定する。

固有振動数`f_n=(1/2π)√(K/I)`はこの案の主目的ではなく、`I`,`K`の変更に伴う結果として追跡する。球径・質量・位置と錘質量・位置を独立変数にし、下側錘を含む全体の`I`,`K`、風トルクを計算する。ダンパー追加は改修規模が大きいため今回の比較から外す。

現行の計測記録では、球は直径100 mm、質量3.9 g、幾何学的な支点—球中心距離174 mmである。周期適合の一部では有効腕長180.61 mmが得られているが、これは独立した寸法測定値ではない。両者を混同せず、174 mmを幾何基準、180.61 mmを係数同定上の感度ケースとして扱う。

現行BALL係数の出典は[係数設定](../../../config/hbk_model_coefficients.json)、幾何・質量の記録は[物理入力一覧](../../../../fitting_pipeline/results/20260921/physical_input_sources.csv)と[取付寸法・質量表](../../../../fitting_pipeline/results/20260921/FITTING_REPORT.md)にある。

## 力学モデルと評価

部品ごとの質量 `m_i`、支点からの符号付き重心位置 `r_i`、重心まわり慣性 `J_i` から、次を再計算する。

```text
I = Σ (J_i + m_i r_i²)
K = g Σ (s_i m_i r_i)       # s_i は既存モデルの復元方向に合わせる符号
τ_w ≈ 0.5 ρ Cd (πD²/4) ℓ_w V|V|
f_n ≈ (1/2π) √(K/I)         # 無風・小振幅の一次目安
```

球径 `D`、球質量、球中心腕長 `ℓ_w`、錘質量、錘腕長は独立に入力する。球の材質を変えるケースでは、質量と直径を同密度の比例則で固定せず、実測値を使う。測定した軸摩擦`τ`を固定したケースで`I`,`K`と`8τ/(Kθ_A)`を算出し、`K`低下による摩擦相対効果を評価する。その後、採用候補の非線形運動方程式で0〜10 Hzの風感度、係数誤差感度、微風の不感帯を評価する。受風面積による角度振幅の増加だけを改善判定に使わない。

| 段階 | 比較条件 |
|---|---|
| 球単独 | 80/100/120 mm級と、約8 m/sで角度リミットを満たすための計算上の小径候補、軽量球と同密度球、腕長174/164/154 mmを組み合わせ、`I`,`K`,`τ`相対効果・共振応答への影響を確認する。クリアランスを満たさない組合せは除外する。|
| 錘単独 | 実測質量・位置を基準に、過去案の35.874 g・47.832 gと、80 mmを中心とする70/80/90 mmの仮位置を比較する。物理的に取れない位置は実装可能範囲に置き換える。|
| 組合せ | 球の有力2〜3条件と錘の有力2〜3条件を組み合わせ、摩擦相対効果、共振ピーク、風速レンジ、微風応答をIN/OUT両軸で解析する。|
| 誤差・入力 | 1 Hz正弦、0〜10 Hz掃引、Kaimal乱流、ガスト、自由減衰にOW-04係数ずれとOW-05仮定ノイズを加える。|

評価では、時間ずれを許容した波形形状と振幅保持を分ける。固定`τ`に対する`8τ/(Kθ_A)`、自由振動の減衰・停止振幅、共振ピーク、約8 m/s時の最大角度を主に示す。許容ラグ後の相関・RMSE、1 Hzおよび周波数別の振幅ゲイン、ノイズ感度、静的感度、低風速の不感帯・ヒステリシス、±60°接触も併記する。減衰が増えても微風が動かない、または最大風速で角度リミットを超える場合は採用しない。

## スコープ

新たな実測は行わず、既存の自由振動解析で得た運動摩擦`τ`、利用可能な停止角・部品仕様、静止摩擦に関する公開資料から`τ_s`の推定範囲を作る。その範囲を用いて、球・錘の最小変更における約8 m/sの角度上限、起動風速、推定可能風速下限、応答性のトレードオフを評価する。成立しない場合は、必要な粘性減衰と実装可能なダンパーを評価する。古典的な過減衰を実現するダンパー案と、軸クーロン摩擦を相対的に強める質量配置案は、別の機構として比較する。
