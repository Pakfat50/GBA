# OW-07 ハードウェアによる風推定帯域改善案

## 状態と目的

- 状態: 提案段階。ここでは解析方針と優先候補をまとめる。部品設計・購入・製作判断は行わない。
- ブランチ: `ow07-hardware-bandwidth-design`
- 起点: `ow06-frequency-aware-observer-design`
- 目的: オブザーバー方式の変更だけでは一般化できる改善を確認できなかったため、機械系と計測系を変え、0〜10 Hzの風変動を推定できる構成を検討する。

## 提案の要約

まず、**可動部の慣性を小さくし、非接触の調整可能な回転ダンパーを加える案**を優先して解析する。前者は低周波の静的感度を保ちながら固有振動数を上げる可能性があり、後者は固有振動数付近の過大応答を抑える役割を持つ。両方を単独・組合せで比較し、要求帯域全体で風の振幅と波形形状を保てるか確認する。

現在の採用BALL係数による無風・小振幅の固有振動数はIN約1.015 Hz、OUT約0.985 Hzである。固有振動数を上げるには、比 `K/I` を大きくする必要がある。現状から2、3、5、10 Hzへ移すために必要な `K/I` の倍率は概算で次のとおり。実際の風速・振幅・空力減衰・非線形性を含む値ではなく、設計規模を示す一次見積りである。

| 目標固有振動数 | INのK/I倍率 | OUTのK/I倍率 |
|---:|---:|---:|
| 2 Hz | 3.9倍 | 4.1倍 |
| 3 Hz | 8.7倍 | 9.3倍 |
| 5 Hz | 24.3倍 | 25.7倍 |
| 10 Hz | 97.2倍 | 103.0倍 |

`K`を保って`I`だけを下げる場合は、表の倍率分だけ慣性を小さくする必要がある。10 Hzまで固有振動数を引き上げる案は大きな変更になるため、まず2〜5 Hzを含む掃引で、慣性低減と減衰の組合せに実用的な範囲があるか調べる。10 Hz帯域を通すことと、機械固有振動数そのものを10 Hzにすることは同じ要件ではない。

## 候補と現時点の根拠

### A. 非接触の回転ダンパー

第一候補は、アルミ板と対向ネオジム磁石を使う渦電流ダンパーを、磁石間隔などで調整できる形にする案。以前の理想角度シミュレーションでは、追加粘性係数 `b=1e-4` と `3e-4 N·m·s/rad` により、1 Hz付近の推定ゲインピークを下げられた。`b=3e-4`ではピークがIN 1.66、OUT 1.45まで下がった一方、1には戻っていない。10 Hzゲインが約1となった結果も、高いプロセス雑音設定・センサーノイズなしの条件であり、実機達成の根拠ではない。

したがって、この結果は「ダンパー係数の測定範囲を決める初期情報」として使い、採用値とはみなさない。15 mmアルミ板案は成立を前提にせず、取付け空間と必要減衰係数を結び付けて評価する。温度、磁石間隔、組立公差、二軸ごとの差、追加摩擦の有無を測る。軸受摩擦や静止摩擦を増やす方式は、低風速時の不感帯を作るおそれがあるため、非接触方式を先に調べる。

### B. 可動部の慣性低減

球の受風面積とピボットからの腕長をなるべく保ちながら、ロッド・支持部・可動取付け部の質量を減らす案を比較する。`K`が大きく変わらなければ、`I`低減は固有振動数を上げつつ低周波の静的な風感度を直接下げにくい。ただし、球位置や釣合い錘を変えると、慣性、復元係数、風トルク、可動域が同時に変わる。部品ごとの質量・重心・慣性をモデルに反映し、風トルク腕長を失う案は別条件として扱う。

### C. 計測帯域と角度検出

現在のシミュレーションは100 Hz標本化、MT6701相当14 bit、遅延10 msなどを仮定している。10 Hzは100 Hzで1周期あたり10標本だが、30 Hzは約3.3標本しかない。30 Hzを理想目標として検討する場合は、センサー・読出し・記録系の実効帯域と標本化を別途上げて確認する。事後処理なので計算遅延は制約にしないが、収録時の標本化、遅延、アンチエイリアス、角度ノイズは制約に残る。

## 設計前に解消する基準値の差

現行シミュレーションの採用BALL値は、球質量3.9 g、球中心腕長180.61 mmである。一方、幾何寸法からの球中心位置は174 mmという既往値があり、180.61 mmは周期合わせから得た有効腕長で、独立した実測寸法ではない。球質量にも従来の約5 gという概算がある。ハード寸法を最適化する前に、ピボットから球中心までの実距離、球と可動部の質量・重心を再計測し、幾何値と同定値の差を切り分ける。差が残る場合は両方を感度範囲に含める。

## 評価の考え方

- 0〜10 Hzの周波数掃引に加え、1 Hz正弦、Kaimal乱流、ガスト、自由減衰を比較する。時間ずれを許容するため、位相遅れだけを合否条件にしない。
- 波形形状は許容ラグ後の相関・RMSEで、振幅保持は基本波または周波数別ゲインで別に評価する。振幅補正をして形状評価を良く見せない。
- 評価はIN/OUT別に行い、平均風、入力振幅、センサーノイズ、係数ずれ、温度、ダンパー個体差を含める。
- まずハード条件を比較する段階では、推定器を固定して機械変更の効果を分離する。その後、最有力候補だけ推定器を再調整し、最終組合せを評価する。
- センサー雑音なしの過去の`b`掃引や合成係数校正を、実機の達成結果として扱わない。

## スコープ

このブランチでは提案と解析計画をまとめる。数値シミュレーション、部品選定、発注、製作、実機改修はまだ行わない。次段階では、寸法の差を解消し、ノイズ・係数ずれを含むパラメータ掃引で候補を絞る。
