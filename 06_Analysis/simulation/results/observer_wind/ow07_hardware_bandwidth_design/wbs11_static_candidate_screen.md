# OW-07 WBS 1.1 — 静的成立性を確認した最小変更候補

## 結論

球・錘の寸法候補を、現行のI/K・空力・静止摩擦シナリオに照らして事前評価した。最大風速8 m/sで±60°以内に保つ球径は、錘質量・位置を変える場合おおむね56〜75 mmとなる。現行錘のままならOUT軸で約73.6 mmが上限なので、余裕を見て70 mmを第一候補とする。80 mm以上の同密度球、現行100 mm球はこの静的条件を満たさない。

一方、球・錘の変更だけで古典的な臨界減衰・過減衰にはできない。採用モデルの線形粘性係数はb=0で、クーロン摩擦と速度二乗抵抗は線形化した臨界減衰係数にならない。1°振幅でのエネルギー等価減衰比も全候補で1未満である。よって本候補は「真の臨界／過減衰案」ではなく、静的角度制約と摩擦の相対寄与を比較する案である。古典的な臨界減衰が必須なら、別途粘性ダンパーが必要になる。

## 基準値と計算条件

- 球の現行値: D0=100 mm、m0=3.9 g、符号付き腕長 rb=-174 mm。
- 錘組立: ホシモトH-10-24丸ボス44.8 g、SC 0505Cカラー2個。寸法からの環状カラー質量は約2.96 g/個（止めねじを除く）。現行組立を約50.7 g、重心 rw=+55 mmとする近似。配置・仕様は[WBS 0基準報告](wbs00_baseline_stiction_requirements.md)参照。
- 同じ試験組立の採用BALL係数を起点にする。IN: I=3.68212e-4 kg m²、K=0.0149632 N m/rad。OUT: I=3.70938e-4 kg m²、K=0.0142211 N m/rad。
- 軸摩擦は現行値のまま固定（IN 7.9457e-5 N m、OUT 1.7695e-4 N m）。軸受・ロッド変更はこのWBS候補に含めない。
- 球径変更では現行球と同じ密度を仮定し m(D)=3.9(D/100)^3 g、球空力抗力係数を一定とする。球径変更後の実質量・抗力係数は未確認。
- 静的な最大角度は、摩擦を除いた保守側の釣合い Mw=K sin(theta) から評価。rho=1.225 kg/m³、Cd=0.544、腕長174 mmを使う。現行100 mm球の風トルク係数は B100=4.5499e-4 N m/(m/s)^2で、直径変更時は面積比 D²/D0²で換算する。
- K変更は球を現在から外した差分と錘の差分で求める。球の符号付き位置は負、錘は正。実際の空力抗力、低Reynolds数、製作誤差、重心ずれはWBS 1.2で感度を確認する。

## 静的成立性から選んだ候補

錘の質量・位置は現行組立約50.7 g・55 mmを基準にする。候補径は各錘案に対し、OUT軸が8 m/sで60°を超えない直径上限より小さく選んだ。

| ID | 錘質量・重心 | 球径・同密度時質量 | 8 m/sでの静的角度 IN/OUT | 起動風速シナリオ IN/OUT | 判定 |
|---|---|---|---:|---:|---|
| P0 | 約50.7 g・55 mm（現行） | 70 mm・1.34 g | 47.6° / 50.1° | 0.60–0.93 / 0.70–1.26 m/s | 第一候補。角度余裕と変更量の基準 |
| P1 | 47.832 g・55 mm | 68 mm・1.23 g | 48.5° / 51.4° | 0.62–0.96 / 0.72–1.29 m/s | 軽い錘変更。調達・取付け要確認 |
| P2 | 約50.7 g・50 mm（5 mm内寄せ） | 65 mm・1.07 g | 45.3° / 48.0° | 0.65–1.00 / 0.75–1.35 m/s | 軽い位置変更。ロッド上で固定可能か確認 |
| P3 | 35.874 g・55 mm | 55 mm・0.65 g | 44.8° / 48.5° | 0.76–1.18 / 0.89–1.60 m/s | 最大風速は満たすが受風面積が小さく、低風速に不利 |
| P4 | 約50.7 g・45 mm（10 mm内寄せ） | 60 mm・0.84 g | 43.6° / 46.4° | 0.70–1.08 / 0.82–1.47 m/s | 角度は満たすが内寄せ量と低風速側を要確認 |

起動風速はWBS 0の現行100 mm球の幅を100/D倍した概算である（Cd一定、球腕長一定）。これは停止状態から静止摩擦を越える値であり、最低計測可能風速を意味しない。推定可能下限は角度ノイズ・復元トルク・起動／停止ヒステリシスを加えてWBS 1.2で求める。

錘案ごとの8 m/s・60°条件から得る球径上限は、W0約73.6 mm、W1約71.0 mm、W2約58.6 mm、W3約69.3 mm、W4約64.7 mm（OUT軸が制約側）。表の直径は端数を下げて余裕を残した。80 mm球は現行錘でも条件を満たさず、120 mm球および100 mm球の内寄せも満たさないため、今回の静的成立候補から外した。

## I・K、周波数、減衰の照合

各候補のIは、現行Iに対する球の mℓ²+Jc と錘の重心移動・質量変更を差分加算した概算。Kは現行係数へ球・錘の符号付き重力モーメント差を加算した。固有振動数は小振幅値 fn=(2pi)^-1 sqrt(K/I)。

| ID | I [10^-4 kg m²] IN/OUT | K [N m/rad] IN/OUT | fn [Hz] IN/OUT | 1°での等価減衰比 IN/OUT |
|---|---:|---:|---:|---:|
| P0 | 2.874 / 2.901 | 0.01934 / 0.01859 | 1.305 / 1.274 | 0.15 / 0.35 |
| P1 | 2.752 / 2.779 | 0.01797 / 0.01723 | 1.286 / 1.253 | 0.16 / 0.37 |
| P2 | 2.525 / 2.552 | 0.01730 / 0.01656 | 1.318 / 1.282 | 0.17 / 0.39 |
| P3 | 2.212 / 2.239 | 0.01250 / 0.01176 | 1.197 / 1.154 | 0.23 / 0.55 |
| P4 | 2.213 / 2.240 | 0.01521 / 0.01446 | 1.319 / 1.279 | 0.19 / 0.45 |

採用モデルのb=0。20260921自由振動フィットの線形bもIN 1.16e-8、OUT 3.45e-5 N m s/radで、候補の臨界係数 bc=2 sqrt(IK) 約0.00325–0.00471 N m s/radの1%未満である。したがって線形化した系は全候補で臨界・過減衰ではなく、実質的に不足減衰である。

クーロン摩擦・二乗抵抗を正弦振動1°振幅で等価粘性化した zeta_eq は、振幅依存の比較指標であって古典的な減衰比ではない。表の最大でも0.55で、1°振幅で臨界相当には届かない。極小振幅で zeta_eq >= 1 となる範囲は静止摩擦による固着・不感帯であり、過減衰達成とはみなさない。球・錘の質量配置だけで古典的な臨界減衰を達成する案は、このモデルからは得られない。

## WBS 1.1の判定と次段

WBS 1.1では、8 m/sの角度制約に対する静的な候補を得た。実装可能性と静止摩擦の起動値を含めた第一比較はP0・P1・P2とし、P3・P4は低風速側の代償が大きい強めの比較案として残す。120 mm案・80 mm以上案などの静的に不成立な条件は候補から除外した。

ただし、候補は臨界・過減衰条件を満たさない。したがって「過減衰または臨界減衰」が必須要求なら、球・錘変更だけで目標達成できるとの見込みはない。WBS 1.2ではP0–P2の起動・推定可能風速下限、軸角±60°と角度リミット余裕をさらに見積もり、低風速目標が設定された場合に成立するかを示す。粘性ダンパーを含む古典的な減衰設計は、計画上のWBS 2で必要係数を評価する。
