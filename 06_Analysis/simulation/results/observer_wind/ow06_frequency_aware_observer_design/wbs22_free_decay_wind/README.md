# WBS 2.2 補足：自由振動・風入力での係数ずれ比較

## 結果の要点

係数ずれをプラント側だけに与え、推定器には公称BALL係数を使った。自由振動では、OW-04の相関付き係数ずれが推定風の誤差を固有振動数近傍に生じさせた。RTSは前向きEKFより後処理誤差を改善するが、このモデル誤差成分はほとんど減らない。固定ゲイン `Fixed_p5` も同程度の誤差で、係数ずれへの特別な耐性は確認できなかった。

乱流ではRTSの総合RMSEが最小だったが、係数ずれによる平均バイアスが約0.10 m/s残り、固有振動数近傍の誤差も増加した。したがって、事後平滑化は位相・確率誤差には有効でも、誤ったプラント係数から生じる系統誤差を自動で補正しない。

## 条件

- サンプル周波数100 Hz、OW-03の非線形BALLモデル。
- 係数ずれ: OW-04の `joint_mass_high_arm_high_tau-high_c-high` 相関ケースを**真のプラントだけ**に印加。EKF、RTS、固定ゲイン推定器は公称係数を使用。
- 自由振動: 初期角30°、初期角速度0、全期間で外力・風速ゼロ。±60°ストップ範囲内で解放。
- 風入力: 既存の独立Kaimal乱流（平均2 m/s、TI 20%）およびガスト（2→6 m/s）。
- センサー: 理想角度（雑音、遅延、量子化なし）。係数ずれ単独の効果を分離する試験。
- 推定器: `EKF_q1`、同じ前向きEKFの全記録RTS平滑化 `RTS_q1`、2 m/s設計点の固定ゲイン `Fixed_p5`。
- 無風の自由減衰は0.5秒以降、風入力は既存設定どおり15秒以降を採点。
- 固有振動数帯誤差は公称の小信号固有振動数の0.75〜1.25倍を4次Butterworth帯域通過後にRMS化。INは1.015 Hz、OUTは0.985 Hz。

これは風の真値を利用できる**シミュレーション上の切り分け試験**であり、実測時に角度データだけから風と係数ずれを識別できることは意味しない。

## 自由振動：推定風の誤差

真の風速は0 m/s。表は全時間RMSEと、固有振動数近傍の誤差RMS（後者は平均バイアスを除去していない帯域成分）。単位はm/s。

| 軸 | 係数条件 | EKF RMSE | RTS RMSE | Fixed_p5 RMSE | RTS 固有振動数帯RMS |
|---|---|---:|---:|---:|---:|
| IN | 公称一致 | 0.000 | 0.000 | 0.000 | 0.000 |
| IN | OW-04ずれ | 0.500 | 0.501 | 0.513 | 0.341 |
| OUT | 公称一致 | 0.000 | 0.000 | 0.000 | 0.000 |
| OUT | OW-04ずれ | 0.348 | 0.348 | 0.367 | 0.230 |

一致・無雑音で誤差が0なのは、生成プラントと推定器が同じ決定論的モデルだからであり、実機性能の予測値ではない。係数ずれ条件では実際には風がないのに、自由減衰を説明するための外力を推定してしまう。RTSのEKF比改善はこの誤差では見られない。

## 風入力：全帯域RMSE / 固有振動数帯誤差RMS

| 軸 | 入力 | 係数条件 | EKF | RTS | Fixed_p5 |
|---|---|---|---:|---:|---:|
| IN | Kaimal | 公称一致 | 0.163 / 0.054 | 0.083 / 0.007 | 0.147 / 0.021 |
| IN | Kaimal | OW-04ずれ | 0.206 / 0.101 | 0.148 / 0.068 | 0.188 / 0.083 |
| OUT | Kaimal | 公称一致 | 0.128 / 0.025 | 0.063 / 0.006 | 0.274 / 0.025 |
| OUT | Kaimal | OW-04ずれ | 0.170 / 0.051 | 0.128 / 0.031 | 0.259 / 0.041 |
| IN | ガスト | 公称一致 | 0.027 / 0.00014 | 0.00063 / 0.00013 | 0.010 / 0.00012 |
| IN | ガスト | OW-04ずれ | 0.165 / 0.00023 | 0.162 / 0.00025 | 0.163 / 0.00025 |
| OUT | ガスト | 公称一致 | 0.013 / 0.00005 | 0.00006 / 0.00002 | 0.007 / 0.00022 |
| OUT | ガスト | OW-04ずれ | 0.172 / 0.00044 | 0.171 / 0.00045 | 0.172 / 0.00048 |

ガスト入力は固有振動数付近の入力成分がほぼないため、その帯域RMSは小さくても共振付近の追従性を判定できない。ガスト行は全帯域RMSEと約0.15 m/sの正バイアスを主に見る。Kaimal乱流は共振帯成分を含むため、帯域比較に適している。係数ずれでRTSの全帯域RMSEはIN 0.083→0.148、OUT 0.063→0.128へ増えた。固有振動数帯RMSもそれぞれ0.007→0.068、0.006→0.031へ増えた。

## `Fixed_p5` の意味

`p5` は5 Hzの試験入力や機械固有振動数を意味しない。固定ゲイン観測器の設計時に、推定誤差の離散閉ループ極を5 Hz相当の速さに配置した設定である。サンプリング100 Hzで極の半径を `exp(-2π·5·0.01)` とし、設計動作点は風速換算2 m/s。ゲインは解析区間中に固定する。機械の小信号固有振動数は今回のBALLモデルで約1 Hz。
