# WBS 1.2 周波数感度プロット

このフォルダーには、周波数に対する次の3種類の感度を示す図と、再作図用データを保存する。

1. 物理プラントの入力力から角度への感度
2. 角度計測ノイズから推定風速への感度
3. 係数ずれによる推定力ゲイン誤差

## A. 物理プラントの感度

`physical_sensitivity_vs_frequency.svg` は、線形化した伝達関数ではなく、非線形運動方程式を数値積分して得た有限振幅応答である。各周波数での基本波振幅比

\[
S_{F\to\theta}(f) = \frac{|\theta_1(f)|}{|F_1(f)|}
\]

を示す。ここで、\(F_1\) は加振力の振幅、\(\theta_1\) は整定後の角度波形から正弦・余弦・定数項を最小二乗フィットして求めた基本波振幅である。この量は有限振幅条件に依存し、微分としての小信号感度 \(d\theta/dF\) ではない。

- 新ハードのBALL係数によるIN/OUT各1自由度モデルを使用。復元トルクと力トルクのsin/cos項を保持し、二乗抗力を含めた。
- 平均力は2 m/s相当、加振力振幅は平均力の0.35倍、周波数は0.2〜2 Hz。
- 摩擦は運動時のクーロン摩擦 \(\tau\,\mathrm{sgn}(\dot\theta)\) とし、\(\mathrm{sgn}(0)=0\) とした。静止摩擦、固着、stick-slipはモデルに含まない。
- RK4積分刻みは0.002 s、出力間隔は0.01 s。評価区間は開始後 \(\max(5\,\mathrm{s},3/f)\) から終了まで。複数の代表条件では刻みを半分にした確認も行った。
- 最大角度は全積分区間で確認し、機械可動域±60°と比較した。

この計算では、INの最大基本波感度は0.98 Hzで約12,978 deg/N（全区間最大角59.50°）、OUTは0.975 Hzで約10,918 deg/N（49.60°）となった。INは±60°に近いため、その近傍の応答を線形・小振幅として解釈できない。値は、採用した理想的な運動摩擦則・入力振幅・平均風条件の数値結果であり、実機で確認されたピークではない。低振幅・速度ゼロ近傍での固着が実測上問題となる場合には、静止摩擦則の同定とstick-slipモデルが必要になる可能性がある。今回比較した有限振幅条件では厳密sgnとtanhの基本波応答はほぼ一致しており、この追加測定を直ちに必須とはしない。

## B. 角度計測ノイズの感度

`noise_sensitivity_vs_frequency.svg` は、角度計測に加えた単一周波数の0.02°誤差に対する、RTS推定風速の基本波振幅比を示す。既存の `ow06_rts_angle_noise_transfer.csv` の結果をプロットしたもので、2 m/s相当、100 Hz、非線形3状態RTSのシミュレーション条件である。プロセス雑音設定はINがq=3e-5 N/sample、OUTがq=3e-4 N/sample。

これは物理プラント単体の感度ではなく、仮定したプラント摩擦則・推定器・雑音設定を合わせたシミュレーション上の伝搬感度であり、実測ノイズ感度ではない。

## C. 係数ずれの感度

`coefficient_error_sensitivity_vs_frequency.svg` は、OW-04係数ずれ100%条件でのRTSシミュレーションをプロットする。縦軸は推定力ゲインの相対誤差

\[
100\left|\frac{\text{推定力の基本波振幅}}{\text{印加力の基本波振幅}}-1\right|\ \% 
\]

で、力振幅比0.10、0.25、0.35の3条件を表示する。元データは `ow05_force_gain_frequency_response/force_gain_metrics.csv`。tanh摩擦を含む既存のOW-05モデルとRTS設定による結果であり、実機係数ずれの実測ではない。
