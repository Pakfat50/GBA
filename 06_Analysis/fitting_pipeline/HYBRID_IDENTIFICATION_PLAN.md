# ハイブリッド自由減衰同定 計画・固定仕様

## 1. 文書の目的

本書は、球抗力式風速計の自由減衰データから物理係数を同定する次段階の作業を、
再現可能かつレビュー可能な単位に分割するための固定仕様である。

周期・既知形状から陽に求められる量はフィッティングから分離し、減衰係数は
線形化したエネルギー式ではなく、非線形運動方程式の厳密な半周期数値積分で
同定する。各波形固有の初期条件やオフセットをフィッティング変数にはしない。

本書の承認後は、各Stageを独立したコミットとして実装・検証する。各コミット後に
作業を停止し、レビュー承認を受けるまで次のStageへ進まない。

## 2. 対象範囲

### 2.1 対象

- `04_Data/05_Fitting/20260921/` の確認済み自由減衰波形
- IN軸、OUT軸
- 球なしのSP00～SP04
- 球ありのBALL
- 頂点周期による `I`、`K` の同定
- 頂点間の非線形数値積分による `b`、`c`、`tau` の同定
- 固定した代表係数による全実波形の再現性評価

### 2.2 本作業では対象外

- 定常風データによる抗力係数の最終較正
- センサーオフセットのフィッティング
- 波形ごとの物理係数の採用
- オブザーバーへの係数反映（自由減衰同定の承認後に実施する）
- 方向別摩擦、荷重依存摩擦、非線形ばね項の初期モデルへの導入

対象外のモデルは、基本モデルに系統残差が残った場合だけStage 7で一つずつ比較する。

## 3. 基本運動方程式

自由減衰モデルは次式とする。

```math
I_j\ddot\theta
+K_j\sin\theta
+b_a\dot\theta
+c_j|\dot\theta|\dot\theta
+\tau_a\tanh(\dot\theta/\varepsilon)=0
```

- `j`: 形態（SP00～SP04、BALL）
- `a`: 軸（IN、OUT）
- `I_j`, `K_j`: 形態ごとに周期と既知形状から決定する
- `b_a`, `tau_a`: 軸ごとの代表値
- `c_j`: ロッドと球の物理的共有条件から決定する
- `epsilon`: クーロン摩擦の符号関数を連続化する既定値。係数同定と検証で同じ値を使う

同定式と全波形検証式で摩擦モデルを変更しない。陽エネルギー法で用いた理想符号関数と、
全波形検証で用いた `tanh` の不一致は解消する。

## 4. パラメータの決定方針

| 項目 | 範囲 | 決定方法 | 減衰フィットでの扱い |
|---|---|---|---|
| `I_j` | 形態・軸ごと | 有限振幅周期、既知の追加慣性・形状 | 固定 |
| `K_j` | 形態・軸ごと | 有限振幅周期、既知の追加復元力・形状 | 固定 |
| `c_rod` | 全形態・両軸共通 | 球なし全波形の同時同定 | 共有変数 |
| `c_sphere` | BALL・両軸共通 | 球あり波形を加えた同時同定 | 共有変数 |
| `b_IN`, `b_OUT` | 軸ごと | 厳密な頂点間遷移から同定 | 軸別変数 |
| `tau_IN`, `tau_OUT` | 軸ごと | 厳密な頂点間遷移から同定 | 軸別変数 |
| 平衡中心 | 波形ごと | 決定論的な前処理 | フィットしない |
| 初期角度 | 波形ごと | 最初の採用頂点の実測値 | フィットしない |
| 初期速度 | 波形ごと | 頂点なので0 | フィットしない |
| 時間原点・位相 | 波形ごと | 最初の採用頂点を `t=0` とする | フィットしない |
| センサーオフセット | 波形ごと | 本段階では扱わない | フィットしない |

球あり形態の二乗減衰係数は次式とする。

```math
c_{BALL}=c_{sphere}+\alpha_{rod}c_{rod}
```

球によってロッド先端100 mmが隠れるため、全長229 mm、露出長129 mm、回転抗力の
長さ4乗則から、幾何係数は次の固定値を用いる。

```math
\alpha_{rod}=(129/229)^4\simeq0.101
```

`b_IN` は既存結果で実質ゼロであるが、計算方法が変わるためStage 4の最初の同定では
自由変数に含める。その後、`b_IN` 自由モデルと `b_IN=0` 固定モデルを同じ評価条件で
比較し、検証誤差が悪化せず不確かさがゼロを含む場合にのみゼロ固定を採用する。

## 5. 波形前処理と初期状態

### 5.1 データ選択

- `waveform_selection.csv` で承認済みの波形だけを使用する。
- 接触、リミット衝突、記録不良として除外された候補を復活させない。
- 入力CSVを変更しない。
- 周波数同定は現行条件を引き継ぎ、原則として振幅5 deg以上を使用する。
- 減衰同定は現行条件を引き継ぎ、原則として振幅4 deg以上を使用する。
- しきい値の変更は、変更前後の結果を提示してレビューを受ける。

### 5.2 最初の半周期の除外

解放操作、手動保持、初期速度の影響を避けるため、解放後の最初の半周期は同定・検証の
開始状態に使用しない。その次に検出された最初の折返し頂点を最初の採用頂点とする。

頂点は近傍3点の二次補間で時刻と角度を決める。これは決められた前処理であり、
フィッティング変数ではない。

最初の採用頂点時刻を `t=0` とし、初期状態を次のように固定する。

```math
\theta(0)=\theta_{peak}-\theta_{eq},\qquad \dot\theta(0)=0
```

### 5.3 平衡中心

平衡中心はフィッティングせず、正負頂点の包絡線中点から機械的に求める。

1. 正側頂点から上側包絡線 `theta_plus(t)` を線形補間する。
2. 負側頂点から下側包絡線 `theta_minus(t)` を線形補間する。
3. 両包絡線が存在する共通時間範囲で中点を計算する。
4. 中点系列の中央値を波形の平衡中心とする。

```math
\theta_{mid}(t)=\frac{\theta_{plus}(t)+\theta_{minus}(t)}{2}
```

```math
\theta_{eq}=\operatorname{median}_t\left(\theta_{mid}(t)\right)
```

全点平均も比較用に計算するが、主値には使用しない。Stage 1では、包絡線中点、全点平均、
既存の終端中央値を同じ表と概要図に示し、中心推定方法による差をレビューする。

## 6. `I`、`K` の同定

同符号頂点間の実測周期 `T` と代表振幅 `A` に有限振幅補正を適用し、形態ごとの
`q=K/I` を求める。

```math
q=\frac{K}{I}
=\left[\frac{4\mathbf K(\sin^2(A/2))}{T}\right]^2
```

周期だけから絶対値の `I` と `K` を別々に求めることはできない。SP00～SP04では、
スペーサの既知増分 `Delta I_j`, `Delta K_j` と次式を用いて基準値を分離する。

```math
q_j=\frac{K_0+\Delta K_j}{I_0+\Delta I_j}
```

BALLでは、既知形状・質量から求めた `K` と実測 `q` から `I=K/q` を求める。
したがって、球による付加慣性も周期に現れる範囲で `I` に含まれる。

減衰同定後に減衰が周期へ与える影響を確認し、必要であれば一度だけ周期整合性を再評価する。
ただし、全波形誤差を小さくする目的で `I`、`K` を自由に再フィットしない。

## 7. 減衰係数の同定

### 7.1 同定用の半周期予測

各実測頂点 `(A_n, 0)` を初期状態として、基本運動方程式を次の折返しまで数値積分する。

```math
\hat A_{n+1}=P(A_n;I_j,K_j,b_a,c_j,\tau_a)
```

主残差は次の頂点角度とする。

```math
r_{r,n}=\hat A_{r,n+1}-A_{r,n+1}
```

各半周期の開始時に実測頂点へ戻すため、同定中に位相誤差や前区間のモデル誤差を累積させない。
陽なエネルギー式は初期値生成と寄与の診断には使用できるが、最終係数の目的関数には使用しない。

### 7.2 重み付けとロバスト損失

- 各波形の平均損失を計算し、波形数で平均する。
- 半周期数の多い波形が目的関数を支配しないよう、各波形の総重みを等しくする。
- IN/OUTや形態間のサンプル数差を報告する。
- 外れ値に対してはロバスト損失を使用できるが、尺度は実残差分布に基づいて決める。
- ロバスト損失の種類と尺度を結果ファイルへ保存する。

目的関数の基本形は次式とする。

```math
J=\frac{1}{N_{wave}}
\sum_r\frac{1}{N_r}\sum_n
\rho\left(\frac{r_{r,n}}{\sigma_A}\right)
```

### 7.3 同定順序

1. 球なし全波形から `c_rod`, `b_IN`, `b_OUT`, `tau_IN`, `tau_OUT` を同定する。
2. `b_IN` 自由／ゼロ固定モデルを比較する。
3. BALLを追加し、`c_sphere` を含む共有モデルを全データで同時に再同定する。
4. 最終係数を固定して全波形を連続シミュレーションする。

波形別の `b`, `c`, `tau` は診断目的でも最終係数として採用しない。必要な場合は旧個別フィットを
比較対象としてのみ使用する。

## 8. 検証方法

### 8.1 同定時の評価

- 1半周期先の頂点角度RMSE
- 振幅別残差
- 正負方向別残差
- 軸別・形態別残差
- パラメータ相関、ヤコビアン、信頼区間またはプロファイル損失
- 1波形除外交差検証

### 8.2 全波形検証

全波形検証では途中の実測頂点へ戻さず、最初の採用頂点から記録終端まで連続計算する。
この段階で係数を再フィットしない。

- 全サンプル波形RMSE
- 頂点包絡線RMSE
- 周期誤差
- 軸別・形態別・初期振幅別の誤差
- 正負方向別残差
- 誤差の時間推移

プロットは全体概要図を基本とし、個別波形図は既定では生成しない。全波形の数値結果はCSVへ
保存し、問題波形を特定できるようにする。

### 8.3 比較対象と現行ベースライン

20260921データに対する現行結果は次のとおりである。

| 手法 | 係数の自由度 | 波形RMSE平均 [deg] | 中央値 [deg] | 最大 [deg] |
|---|---|---:|---:|---:|
| 従来・波形別同時フィット | 波形ごとに7変数 | 0.818 | 0.805 | 1.907 |
| 従来・軸×形態代表係数 | 軸×形態ごとに `b,c,tau` | 2.282 | 1.843 | 5.654 |
| 陽エネルギー・共有代表係数 | `c`共有、`b,tau`軸別 | 3.067 | 2.856 | 5.671 |

陽エネルギー法の1半周期先角度換算RMSEは0.587 deg、再帰頂点包絡線RMSEは平均2.332 degである。
従来個別フィットは係数数が多く、代表係数モデルの汎化性能を示す値ではないため、到達可能な
波形再現性の参考値として扱う。主比較対象は、従来代表係数と陽エネルギー共有代表係数である。

新手法の採否はRMSEだけで決めず、次を同時に確認する。

- 共有すべき `c` が軸・形態別の誤差を吸収していないこと
- `I`、`K` が周期測定と整合すること
- 振幅または方向に対する系統残差が残っていないこと
- 未使用波形に対する誤差が改善または維持されること
- 採用係数をオブザーバーで一意に使用できること

## 10. 各Stageの完了条件

各コミットには次を含める。

1. そのStageの範囲だけのコードまたは文書変更
2. 自動テストと実行コマンド
3. 使用した設定と入力を追跡できる記録
4. 全体概要図（必要なStageのみ）
5. 全波形または全区間の数値CSV
6. 結果、既知の制約、次Stageへ持ち越す論点を記載したレポート

コミット後は次を報告して停止する。

- ブランチ名とコミットURL
- 変更ファイル
- 実行したテストと結果
- 主要な数値結果
- レビューが必要な判断事項

レビュー承認前に次Stageの実装を開始しない。

## 11. Stage 7へ進む条件

基本モデルの検証後、残差に再現性のある構造が確認された場合だけ追加モデルを検討する。
候補の優先順位は次のとおりとする。

1. OUT軸の方向別 `tau`
2. 荷重依存 `tau`
3. 非線形復元項 `K3*sin(theta)^3`
4. 摩擦連続化モデルの変更

一度に変更するモデル要素は一つとし、同じデータ分割・同じ評価指標で基本モデルと比較する。
学習誤差だけが改善し、交差検証または全波形検証が改善しないモデルは採用しない。
