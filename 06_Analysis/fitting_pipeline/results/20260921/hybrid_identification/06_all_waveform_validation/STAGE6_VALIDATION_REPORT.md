# Stage 6: 同定済み係数による全波形連続検証

## 結果

承認済み46波形、2173半周期を対象に、係数を再フィットせず連続積分した。I・Kと二乗抗力係数cは形態ごと、τは軸ごとにStage 2/4/5の同定値を割り当てた。個別波形図は作成せず、すべての波形を一枚の概要図へ重ねている。

- 波形等重みサンプルRMSE：10.406°（波形RMSEの中央値 10.549°、最大 16.205°）
- 波形等重み頂点包絡線RMSE：2.390°（対応できた連続折返し頂点、状態リセットなし）
- 波形等重み半周期誤差RMSE：79.20 ms（対応頂点間）

- `b_IN=b_OUT=0`、`tau_IN/tau_OUT`はStage 4代表値、球の係数はStage 5推定値で固定。波形ごとの再フィットなし。
- `SP00–SP04`: IN/OUTそれぞれのStage 2 `I,K`、Stage 4の理論ロッド`c_rod`。
- `BALL`: Stage 2の物理加算`I,K`、`c_sphere + c_rod_ball`（Stage 5幾何補正済み）。
- 開始状態は最初の採用頂点の実測角度・ゼロ角速度。以降の実測頂点へ戻さず、最後の採用頂点まで連続積分。角度中心はStage 1確定値。
- RMSEは波形ごとに算出して同じ重みで平均。半周期RMSEはODE折返しイベントとStage 1実測頂点を時系列順に対応させた。
- Stage 1採用範囲の2173半周期のうち、ODE折返し頂点と実測頂点を2163半周期で対応できた。残りは各記録窓の末端でモデルと実測の頂点数が一致しなかった分であり、波形サンプルRMSEにはその位相差も含めている。

頂点包絡線RMSE（2.390°）に比べてサンプル波形RMSE（10.406°）が大きく、半周期誤差（79.2 ms）も蓄積している。これは各折返しの減衰量は概ね追う一方、周期・位相の小さなずれが連続時間とともに蓄積することを示す。指定どおり係数は再調整していないため、このStageでは「局所的な半周期再現」と「長時間の連続予測性能」を別の評価結果として残す。

Stage 6は固定係数の予測性能評価であり、残差を小さくするために`I,K,b,c,tau`や初期条件を調整していない。大きな連続波形誤差は、係数同定ではなく予測・位相誤差としてそのまま報告する。
