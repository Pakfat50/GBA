# Stage 2: 非線形周期によるI、K同定

## 結論

Stage 1で確定した46波形の頂点と中心を使用し、振幅5 deg以上の同符号頂点間周期から
有限振幅補正済み `K/I` を求めた。波形フィッティングによる `I`、`K` の調整は行っていない。
SP00～SP04は既知の追加慣性・追加復元力を使って軸別の基準 `I0`、`K0` を同時同定し、
BALLは既知の重力復元力を実測 `K/I` で割って実効慣性を求めた。

## 同定式

同符号頂点間の周期を `T`、両端のポテンシャルエネルギー平均に対応する代表振幅を `A` とする。

```math
K/I = [4 K_elliptic(sin^2(A/2))/T]^2
```

```math
(K0 + Delta K_j)/(I0 + Delta I_j) = (K/I)_j
```

各波形では周期サンプルの中央値を採用し、軸・形態の代表値は波形代表値の算術平均とした。
ここでの中央値は同一波形内の周期外れ値に対するロバスト化だけに使用する。

## 使用データ

- 波形数: 46
- 周期サンプル数: 2068
- 1波形あたり周期数の範囲: 23～76
- 代表振幅範囲: 5.66～61.35 deg
- 有限振幅補正率の範囲: 1.0012～1.1594

## 残差の要約

- SP00～SP04の最大絶対K/I残差: 1.4993 s^-2
- SP00～SP04の最大絶対相対残差: 1.745%
- 開始方向P-N差の最大絶対値: 0.127% (OUT BALL)
- 波形内周期サンプルの最大偏差: 22.86% (IN_SP00_P_R01、代表振幅16.46 deg)
- 個別周期には頂点時刻ノイズによる外れ値があるため、波形代表K/Iには中央値を採用した。全周期はCSVへ残している。

## Stage 2のレビュー事項

1. 振幅5 deg以上の同符号頂点周期と有限振幅補正を採用するか。
2. SP00～SP04の既知増分から求めた軸別I0、K0を採用するか。
3. BALLのKは重力モデル、Iは実測K/Iから求めた実効値を採用するか。
4. 周期残差と開始方向差を許容し、Stage 3の厳密半周期ソルバーへ進むか。

## 持ち越し事項

- 減衰が周期へ与える影響は、減衰係数同定後に一度だけ再確認する。
- I、Kは後段の波形誤差を下げる目的では再フィットしない。
