# Stage 1: 頂点・平衡中心・初期状態の決定

## 実施内容

- 平衡中心に依存せず極大・極小を抽出
- 各頂点を近傍3点の二次補間でサンプル間へ補正
- 振幅4 deg以上の上下包絡線中点の中央値を平衡中心として固定
- 解放後最初の折返し頂点を時間原点・初期角度として固定
- 初期速度を0に固定
- 全点平均、既存の終端中央値と比較
- 物理係数の同定は未実施
