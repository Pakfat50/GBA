# IKT-04 レポート：I・K調整試行の記録と次段階への判断

- 記録日: 2026-10-01
- 対象: 球なし自由振動34波形（IN 15本、OUT 19本）
- 状態: **IKT-04本来の球あり理論I・K算出は未実施。関連するI・K調整診断を記録し、反復調整は終了**
- 関連する試行: IHB-05「I・K共通調整による連続波形の位相ずれ診断」

## 結論

I・Kを軸ごとに共通調整すると、全波形平均と取り分けた検証波形の誤差は下がった。しかし、SP00〜SP02では交点ずれが悪化し、SP03・SP04では改善するという条件間のトレードオフが残った。SP04にも調整後の誤差が残っており、I・Kだけで全条件のズレが解決したとは言えない。

このため、I・Kの再帰的なフィッティングや追加調整はここで終了する。今回の候補値は正式値として採用しない。その後、未同定だったc_ballをIKT-05で同定した。IKT-04はスキップし、既存の球ありI・Kを固定値として再利用した。次段階では、今回得たc_ballを含む固定モデルの誤差が最終的なオブザーバー誤差にどの程度伝わるかを評価する。

## 試行方法

球なし条件の軸ごとに、既存の基準I0・K0へ共通倍率を適用し、既知のスペーサ増分を加えてSP00〜SP04の値を構成した。調整したのはI0とK0の倍率だけである。τ、ロッド抗力係数、b=0、初期角、初期角速度、計測範囲は固定した。

各軸・各SP条件で再現番号が最も大きい波形を1本ずつ検証用に取り分けた。残りの波形で連続運動方程式のゼロ交点時刻誤差を最小化し、同じ係数を検証波形にも適用した。波形ごとの重みを等しくした。探索範囲は基準値の±5%で、これは物理的不確かさを表す範囲ではなく、改善可能性を調べる診断範囲である。

## 考察と次タスクへの引き継ぎ

平均指標では検証波形を含めて改善しているが、改善は主にSP03・SP04で大きく、SP00〜SP02では一貫していない。したがって平均誤差だけを根拠にI・Kを置き換えると、条件によって誤差を増やす可能性がある。高い周期フィットのR値も、連続波形の位相ずれやオブザーバー出力の誤差が小さいことを直接保証しない。

次タスクでは、現行のI・Kと今回の診断候補を比較対象として保持しつつ、オブザーバーの最終出力誤差を評価する。モデル誤差を入力したときに誤差がどの程度伝播・増幅するかを確認し、必要であればその後に誤差要因を絞る。I・Kの追加最適化は行わない。

なお、本レポートはIHB-05の診断結果をIKT-04の記録先に整理したもので、IKT-04の本来の作業である球あり形態の理論I・K算出を実施したという意味ではない。IKT全体の終了判断およびIKT-04未実施の状態は変更しない。I・K診断の詳細条件と図表はIHB-05レポートを参照する。
