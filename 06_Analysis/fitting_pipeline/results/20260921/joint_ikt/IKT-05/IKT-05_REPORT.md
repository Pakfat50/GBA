# IKT-05 レポート：球抗力係数 c_ball の同定

- 実施日: 2026-10-01
- 対象: 承認済み球あり自由振動波形12本、379半周期（IN 6本、OUT 6本）
- 状態: **c_ballを同定。IKT-04はユーザー判断によりスキップ**

## 結論

球あり波形の半周期ごとのエネルギー損失を使い、球の二乗抗力係数を非負の共通値として推定した。今回の固定入力と運動方程式のもとで得た値は、`c_ball = 1.49754e-5 N m s²/rad²`である。波形単位のクラスタ・ブートストラップ95%区間は`1.39273e-5〜1.59982e-5 N m s²/rad²`だった。

推定係数を用いた半周期ODEの次頂点角RMSEは全379区間で0.483°。12本の球あり波形で減衰を表す有効係数を同定できた。ただし、これは採用したI・K・τ・ロッド抗力と球あり波形に依存する等価係数であり、孤立した球の普遍的な抗力係数ではない。

## IKT-04をスキップしたときの固定入力

IKT-04の再計算・再同定は行っていない。球あり形態のI・Kには、以前のハイブリッド解析で保存済みの値を固定入力として再利用した。ここで示す入力値を新しく導出したものではない。

| 軸 | 固定I [kg m²] | 固定K [N m/rad] | 出典 |
|---|---:|---:|---|
| IN | 3.666305e-4 | 1.570141e-2 | 保存済みハイブリッドStage 2のBALL値 |
| OUT | 3.701680e-4 | 1.497976e-2 | 保存済みハイブリッドStage 2のBALL値 |

クーロン摩擦τはIHB-03で選択した半周期ODEの次頂点角フィット値を固定した。INは`8.8238e-5 N m`、OUTは`1.5633e-4 N m`。粘性摩擦は両軸とも`b=0`。球で覆われる部分を除いたロッドの二乗抗力係数は`2.56644e-7 N m s²/rad²`に固定した。c_ball以外を球あり波形に合わせて再フィットしていない。

球ありI・Kは以前のハイブリッドStage 2、τはIHB-03から引き継いだため、これらの係数は同一の再同定パスで得られた一組ではない。IKT-04を飛ばしてc_ballを先に確定するための固定入力の組み合わせである。この係数を今後使う場合は、上記の固定値と一緒に扱う。

## 同定対象と手順

承認表で使用可となった球あり波形のみを使った。リリース直後の初期頂点を取り除き、4°以上の隣接頂点間を半周期として扱った。対象はIN 6波形、OUT 6波形、合計379半周期。半周期数が異なる波形でも一つの波形が支配しないよう、各波形の総重みをそろえた。

各半周期の実測頂点間で失われたエネルギーから、固定したτによる摩擦損失と固定ロッド抗力による損失を差し引き、残った損失を球の二乗抗力項`c_ball * |角速度| * 角速度`で説明した。INとOUTに共通する非負のc_ballを一度だけ線形最小二乗で求めた。その後、推定値を固定したまま非線形ODEを積分し、次の実測頂点と比較した。

## 適合結果

| 指標 | 結果 |
|---|---:|
| c_ball | 1.49754e-5 N m s²/rad² |
| 波形クラスタ・ブートストラップ95%区間 | 1.39273e-5〜1.59982e-5 N m s²/rad² |
| 等価球抗力係数 Cd | 0.591 |
| Cdの同95%区間 | 0.550〜0.631 |
| ODE次頂点角RMSE（379区間） | 0.483° |
| 対象波形・半周期 | 12本・379区間 |

![実測とODE予測の次頂点、および開始振幅に対する残差](ikt05_cball_validation.svg)

以前の球抗力解析値`1.46209e-5 N m s²/rad²`との差は約+2.4%。今回はτをIHB-03の選択値へ更新したことによる変化である。係数が桁違いに変わることはなかった。

Brown–Lawler定常球抗力相関を各半周期の速度範囲でエネルギー重み付けした比較値は`Cd=0.418`であり、今回の等価Cd=0.591は約41%高い。往復運動の非定常性、支持ロッドとの干渉、固定した摩擦値・I/Kの差などを含む可能性がある。この差をc_ballだけで補正し、他の係数を再調整することはしていない。

ブートストラップ区間は波形間のばらつきだけを表し、I・K・τ、寸法、球表面状態や相関式自体の不確かさは含まない。また、ODE RMSEは同定に用いた波形内の適合指標であり、独立波形での汎化誤差ではない。

## 次のオブザーバー評価へ

c_ballの同定は完了した。オブザーバー評価では、このc_ballだけでなく、本レポートの固定I・K・τ、b=0、ロッド抗力の設定をまとめてプラント側に渡す。モデル係数の誤差をオブザーバー最終出力誤差へ伝播させる評価を行い、c_ballの系統差やパラメータの出典差が結果へ与える影響を記録する。
